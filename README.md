# Incident Triage Agent

Incident Triage Agent is a Python-based AI workflow agent for automating post-incident handling from operational tickets and alerts.

It is designed to process signals generated by `modern-user-product-order-system` and drive human-reviewed automation workflows.

## Current Scope

Two scenarios are currently in scope:

1. `Ticket -> Workflow -> Review -> Automation Requirements Document`
2. `Alert -> Workflow -> Review -> Automated Remediation`

Review in both scenarios means:

- the agent must generate a human-readable review report
- a human reviewer must approve before any downstream automation step

## Project Structure

- `agents/`: workflow and agent behaviors
- `api/`: external service endpoints
- `config/`: settings and prompt assets
- `eval/`: benchmarks and quality metrics
- `llm/`: model client and prompt orchestration
- `memory/`: short-term and long-term memory modules
- `rag/`: retrieval and knowledge pipeline components
- `tools/`: integrations and execution tools
- `infra/`: runtime and deployment assets
- `docs/`: architecture and requirements documents

## Current Implementation Focus

Build a complete vertical slice for Scenario 1 first, then extend the same review-governed workflow foundation to Scenario 2.
